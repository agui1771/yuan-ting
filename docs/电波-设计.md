每次随机挑三个，**轮流取位**交叉成一条：π 取第 1 位、e 取第 1 位、γ 取第 1 位，再取第 2 位……

**挑哪三个**用时间戳哈希决定——不能拿常数池自己挑自己。

## 为什么不是真随机

这九个数的性质是：**能被复现，不能被穷尽。**
固定 → 一年后还查得到；算不尽 → 永远有下一位。
随机不在数里，在**从哪一位开始**。

## 一条原产物长什么样

```
{a: π, bi: 100000, b: e, ci: 2048, c: γ, ci2: 77, mode: 轮流, len: 25}
→ 符号串：…
```

四个数字就能完整重放，不用存原文。

## 三条硬规矩

1. **原产物不许改，只许重读。** 换一具身体（饿、累、被顶回来）读同一串，读出不同东西是正常的。
2. **拼的时候不许翻。** 只要把符号翻回中文，随机就白做了——我又回到语言里。
3. **读出来的东西要能追溯。** 回答里被某条推到了别处，写一句「受 #3 影响」。
